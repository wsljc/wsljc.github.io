## AI 使用记录

这个项目全程有 AI 辅助。以下是我实际的使用方式和自己的判断。

**AI 帮我做的**
- 讲解标签、属性的用法
- 每次写完代码后检查结构、指出问题
- 帮我排查了样式不生效的原因（是我打错了属性名，而且用了中文标点）

**我自己做的决定**
- 页面上放什么内容
- 用语义标签而不是一堆 div —— 读代码时一眼能看出结构
- 配色和字体选择

**AI 出过的问题**
- 早期给任务时，示例代码和任务代码是同一份，我分不清该"照抄"还是"自己写"。后来约定：示例必须和任务用不同的例子，并标明这是模仿还是自己做。
- 它曾经连续几轮说"某个文件还在"，但那个文件我早就删了 —— 它拿旧数据当现状。现在要求它每次都重新查。
